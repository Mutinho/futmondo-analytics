# Escalation Matrix — Sistema de diseño nativo iOS

> Fase: operación. Idioma: castellano; tokens técnicos verbatim en inglés.

Proyecto personal **single-maintainer**: no hay cadena de escalado ni on-call. El propietario es el único responsable y contacto.

| Rol | Persona | Contacto | Cuándo |
|-----|---------|----------|--------|
| Propietario / mantenedor / on-call | El propietario (único) | Canal personal | Cualquier incidente (P3/P4 de cliente) |

No hay herramienta de on-call de pago (coste 0 €). Los incidentes de cliente se atienden cuando el propietario usa/valida la app; no hay SLA de respuesta formal.

## Assumptions & Open Questions

None.
