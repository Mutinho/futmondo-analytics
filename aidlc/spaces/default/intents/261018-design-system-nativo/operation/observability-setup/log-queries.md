# Log Queries — Sistema de diseño nativo iOS

> Fase: operación. Idioma: castellano; tokens técnicos verbatim en inglés.

NO-APLICA: la capa de diseño cliente no produce logs de servidor que consultar. El logging del backend se consulta con `fly logs` (herramienta gratuita, estado heredado), no afectado por este intent.

En el dispositivo, la depuración de la UI nativa usa la consola de Xcode/Console.app durante el desarrollo (coste 0 €), no un sistema de log centralizado.
