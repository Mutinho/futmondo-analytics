# Functional Design — Frontend Components (`backend-refresh-transport`)

> Bolt 1 de F1. Idioma: castellano; tokens técnicos verbatim en inglés.

**NO APLICA.** Este bolt es un ajuste de **backend** (FastAPI); no tiene componentes de frontend.
Los componentes de UI del cliente nativo (`LoginView`/`SplashView`, `AuthViewModel`) pertenecen al
bolt `ios-native-auth` (Bolt 3). El impacto en el frontend existente (PWA Angular) es **cero por
diseño**: el ajuste es aditivo y preserva el canal cookie.
