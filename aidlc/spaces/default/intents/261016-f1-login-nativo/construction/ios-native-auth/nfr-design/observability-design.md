# NFR Design — Observability Design (`ios-native-auth`)

> Bolt 3 de F1. Idioma: castellano; identificadores/código en inglés.

Logging opcional del ciclo de sesión (login OK/fallo, refresh, logout) sin token ni password
(SEC-A3). En F1 la observabilidad real es la validación manual en el iPhone (login → auto-login →
logout).
